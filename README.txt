물음표 — 간단한 학교 질문 웹사이트

주요 기능
- 첫 화면에서 학생 / 교사 선택
- 학생은 가입 없이 바로 입장
- 교사는 서버에 설정한 비밀번호로 입장 (요청한 배포 비밀번호: 12345)
- 공개 게시판, 과목 필터, 검색, 답변
- 한 명의 ‘물음표 선생님’과 학생별 비공개 DM
- 새 메시지 4초 간격 갱신, 읽지 않은 메시지 수, 해결 상태
- 서버 저장으로 서로 다른 기기의 학생과 교사가 대화 가능

코드 구성
web/index.html : 화면
web/style.css  : 디자인
web/app.js     : 화면 동작
worker.mjs     : 서버 API와 권한 검사
schema.sql     : 데이터베이스 구조

로컬 실행 (Node.js 24 이상, 추가 패키지 설치 없음)
1. 이 폴더에서 터미널을 엽니다.
2. npm run build
3. PowerShell에서 $env:TEACHER_PASSWORD = '12345'
4. npm start
5. http://127.0.0.1:4173 에 접속합니다.

서로 다른 사용자로 시험하려면 일반 창에서는 학생, 시크릿 창에서는 교사를 선택하세요.
로컬 데이터는 .local/data.sqlite에 저장됩니다. 서버를 종료해도 데이터는 유지됩니다.
검증: npm test

배포
Cloudflare Workers의 D1 바인딩 DB와 TEACHER_PASSWORD 서버 환경변수를 사용합니다.
Sites 배포 정보는 .openai/hosting.json에 있습니다.
이 소스만으로 기존 Vercel 사이트를 자동으로 수정하지는 않습니다.

이 간단한 버전은 교사 프로필 하나를 사용합니다. 공통 비밀번호를 아는 사람은
그 교사의 받은 대화를 볼 수 있으므로, 여러 교사 운영 시 개별 인증으로 확장하세요.
학생 기록은 브라우저의 익명 세션에 연결됩니다. 다른 기기나 쿠키 삭제 후에는
같은 학생의 과거 대화를 자동 복구하지 않습니다. 사진 첨부와 자료집은 포함하지 않았습니다.
